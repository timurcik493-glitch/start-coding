Теория простыми словами

    
Читайте по порядку или возвращайтесь к нужной теме. Примеры короткие, их можно вставить в песочницу выше и запустить.

    
    

      

        
Что такое программа

        
Программа это список инструкций, которые компьютер выполняет по порядку, сверху вниз. Компьютер не угадывает, что вы имели в виду: он делает ровно то, что написано.

      

      

        
Переменные

        
Переменная это имя, которое ссылается на значение. Так программа запоминает данные и может с ними работать.

        
age = 20
print(age)

      

      

        
Типы данных

        
Числа, строки (текст в кавычках) и логические значения True и False. Тип определяет, что с данными можно делать: числа складываются, строки склеиваются.

        
print(2 + 3)      # 5
print("2" + "3")  # 23

      

      

        
Условия

        
Оператор if проверяет условие и выполняет код только тогда, когда оно истинно. Так программа принимает решения.

        
if age >= 18:
    print("Доступ открыт")

      

      

        
Циклы

        
Цикл повторяет действие много раз. Он нужен, когда надо обойти список или сделать одно и то же несколько раз подряд.

        
for i in range(3):
    print(i)

      

      

        
Функции

        
Функция это именованный блок кода. Вы описываете её один раз и вызываете столько раз, сколько нужно, с разными данными.

        
def hello(name):
    print("Привет,", name)

hello("Анна")

      

    

  


  

    
Теория, часть 2: глубже

    
Темы, которые понадобятся в первом настоящем проекте. Каждую можно читать отдельно.

    

      

        
Списки

        
Список хранит много значений в одном месте и в нужном порядке. Элементы нумеруются с нуля: первый элемент имеет номер 0.

        
fruits = ["яблоко", "груша"]
fruits.append("слива")
print(fruits[0])  # яблоко

      

      

        
Словари

        
Словарь хранит пары «ключ и значение». Удобно, когда нужно быстро найти данные по имени, например поля профиля.

        
user = {"name": "Анна", "age": 20}
print(user["name"])  # Анна

      

      

        
Ввод данных

        
Функция input спрашивает пользователя и возвращает введённый текст. Так программа становится интерактивной.

        
name = input("Как вас зовут? ")
print("Привет,", name)

      

      

        
Ошибки и исключения

        
Если код падает, программа останавливается. Конструкция try и except перехватывает ошибку и делает что-то разумное вместо аварии.

        
try:
    x = int("abc")
except ValueError:
    print("Это не число")

      

      

        
Модули

        
Модуль это готовый набор функций. Его подключают командой import, и не нужно писать всё с нуля. В Python их тысячи.

        
import random
print(random.randint(1, 6))

      

      

        
Поиск в списке

        
Алгоритм это понятная последовательность шагов. Линейный поиск проверяет элементы по очереди, пока не найдёт нужный.

        
def find(items, target):
    for i, item in enumerate(items):
        if item == target:
            return i
    return -1

Частые вопросы новичков

    

      

        Нужен ли опыт в математике?
        
Нет. Для начала достаточно школьной арифметики. Логике программирования учатся на практике, а не на формулах.

      

      

        Какой язык выбрать первым?
        
Python. Его синтаксис читается почти как обычный английский, а задач и библиотек для него очень много.

      

      

        Сколько времени занимает путь?
        
Около 20 минут в день за два-три месяца вы сможете написать собственный небольшой проект. Темп можно менять как угодно.

      

      

        Нужно ли что-то устанавливать?
        
Для первых шагов нет. Потом понадобится установить Python и редактор кода. Мы подскажем, как это сделать, на следующем этапе.
